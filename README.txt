== Ensy Ventilation Control for Homey ==

Control your Ensy InoVent ventilation unit from Homey. Monitor supply, extract, exhaust, outside and heater temperatures and humidity, change fan speed and set temperature, and get notified about alarms such as filter changes.

The unit must be connected to BITZER Smart Connect, which Ensy now uses for InoVent units. Log in with your BITZER Smart Connect account when adding the device.

Tested with InoVent AHU-200 KH; should work for the InoVent series (LMC 311 controller).
